# nooboard

在一台电脑上复制，到另一台电脑上粘贴。

nooboard 帮你在几台电脑之间共享文字、图片和文件。无论是来回复制一段代码、传几张图片，都可以在同一个应用里完成。

它支持 macOS、Windows 和 Linux。电脑之间通过局域网或已有的 VPN 直接连接，不用注册账号，内容也不会经过云端中转。

**[下载安装包](https://github.com/YoRHazero/nooboard/releases/latest)** · [使用指南](docs/user-guide.md) · [常见问题](docs/troubleshooting.md)

## 下载与安装

打开 [下载页面](https://github.com/YoRHazero/nooboard/releases/latest)，在 **Assets** 中找到适合你电脑的安装包：

| 设备                              | 安装包               | 安装方式                                      |
| --------------------------------- | -------------------- | --------------------------------------------- |
| Windows x64                       | `-setup.exe`         | 运行安装程序                                  |
| macOS Apple Silicon（M 系列芯片） | `_aarch64.dmg`       | 打开磁盘映像，将应用放入「应用程序」          |
| Ubuntu 24.04 x64                  | `.deb` / `.AppImage` | 安装 deb 包，或为 AppImage 添加执行权限后运行 |

目前可以直接下载上面三种安装包。Windows 包尚未签名，macOS 包使用临时签名、尚未公证，安装时可能会看到系统提示，请从本仓库的下载页面获取，并查看该版本的安装说明。Linux 用户可以先看一下 [剪贴板兼容性说明](docs/troubleshooting.md#linux-剪贴板不可用)。

## 先把电脑连起来

1. 在两台电脑上打开 nooboard，让它们连上同一局域网，或通过 VPN 互相访问。
2. 在其中一台电脑打开 **设备 → 添加设备**，找到另一台电脑，点击配对。如果没有发现它，也可以输入地址添加。
3. 在另一台电脑点击 **允许配对**，然后回到第一台电脑，输入对方显示的 8 位配对码。
4. 配对完成后，试着复制一段文字，点击首页的木板，选中另一台电脑并发送。接着在那台电脑上粘贴，就能看到刚才的内容。

配对码在 2 分钟内有效。配对过的电脑会被记住，以后重新连接就不用再配对了。如果列表里有同名设备，可以用设备标识区分。更完整的操作说明见 [使用指南](docs/user-guide.md)。

## 复制、粘贴和传文件

默认情况下，发什么、发给谁，都由你选择。点击首页的木板，可以查看剪贴板里的内容，再发送给一台或多台电脑。想传本地文件时，也可以直接在「传输」里选择文件和接收设备。

如果经常在几台电脑之间切换，可以在「设置」中开启自动模式，再到「设备」中为想同步的电脑打开自动发送。之后新复制的文字就会自动同步到这些电脑上，不用每次点发送。图片和文件仍需要手动发送，离线期间复制的文字也不会在重连后补发。

收到的文件可以在「传输」中找到，默认保存在下载目录下的 `Nooboard` 文件夹。之前复制过的文字则可以去「文字历史」里搜索，找到后再次复制即可。暂时不想同步时，可以暂停收发，或关闭「允许接收」。

## 关于数据和隐私

只有双方确认配对后，电脑之间才能共享内容，传输过程使用加密连接。文字历史保存在你自己的电脑上，没有额外加密；如果不想保留，可以在设置中关闭记录，已有的内容可以在「文字历史」里删除或清空。

nooboard 需要电脑之间能够直接连接。如果两台电脑不在同一局域网，需要先通过 VPN 等方式让它们互通，应用本身不提供公网中转或自动穿透。

## 遇到问题

连接不上、收不到内容，或找不到文件时，可以先看看 [常见问题](docs/troubleshooting.md)。如果仍然没有解决，欢迎在 [GitHub Issues](https://github.com/YoRHazero/nooboard/issues) 告诉我们你遇到了什么，带上应用版本、操作系统和报错信息，会更容易定位。记得隐去密码、配对码和私人剪贴板内容。

想了解更多，可以查看 [全部文档](docs/README.md)。如果你也想参与开发，从 [开发与贡献](docs/development.md) 开始即可。
