# SSH 工作区使用指南

[返回 README](../README.md) · [常见问题](troubleshooting.md)

SSH 工作区让你在 nooboard 中使用已配对电脑的终端，并通过 SFTP 浏览和传输文件。

## 连接前准备

- 两台电脑已在 nooboard 中配对，网络能够互通。
- 对方已启用 SSH 服务，允许你使用对应系统账号登录。
- 你知道对方的用户名、密码和 SSH 端口；默认端口是 `22`。
- 文件浏览和传输还需要对方 SSH 服务提供 SFTP。

目前只支持密码认证。仅允许公钥登录、需要多因素交互认证的服务器不能通过当前登录表单连接。nooboard 不会自动启用或修改对方的 SSH 服务。

## 建立会话

1. 打开「SSH 工作区」，点击顶部的「新增会话」。
2. 选择已配对设备，填写用户名、端口和密码。
3. 按需勾选「在系统凭据库中记住密码」，然后连接。
4. 首次连接时，与对方核对地址、密钥算法和 SHA-256 指纹，再选择「信任并连接」。

nooboard 配对与 SSH 主机验证是独立的。配对成功不会自动信任 SSH 指纹；已保存指纹发生变化时会阻止连接，应先向对方确认原因。

每次连接会重新获取设备的地址候选，所以 IP 改变后通常不必重新配对；已经建立的连接不会迁移到新 IP，需要重新连接。在无法发现设备的网络中，应保持对方连接地址有效。

### 记住密码与重连

未勾选记住密码时，密码只用于本次认证。勾选后，仅在认证成功时保存到操作系统凭据库；下次可点击「使用已保存密码」，密码不会回填到输入框。

连接失败后会返回空密码、未勾选记忆的登录表单，原保存密码也不再直接用于一键连接。请根据错误检查网络、端口或账号后重新填写，需要继续记忆时重新勾选。单个文件任务失败或输入了无效目录，并不意味着登录密码失效。

## 终端与布局

顶部管理会话与设备，主区域是终端，右侧是远端文件树，底部是 SFTP 文件传输队列。可在顶部切换会话、收起文件树，也可拖动分隔线调整文件树宽度。

终端与文件连接分别显示状态。一侧出错时，健康的另一侧可以继续工作。例如终端正常但 SFTP 失败时，可以点击「重新连接 SFTP」。

## 浏览远端目录

连接后，文件树从 SFTP 服务提供的初始目录开始，根节点保持收起。只有展开某个目录才会读取其直接子项；不会提前扫描整棵树。大目录分批显示，点击「加载更多」继续读取。

在路径栏输入目录并按 Enter，或点击「打开路径」：

| 输入                  | 含义                           |
| --------------------- | ------------------------------ |
| `/home/alex/projects` | 远端服务中的绝对目录           |
| `projects`            | 相对于文件树当前根目录的子目录 |
| `..`                  | 文件树当前根目录的上一级       |
| 含空格的路径          | 直接输入，无需添加 shell 引号  |

只有确认路径存在且是目录后，才会切换文件树；失败时保留原目录。切换成功后根节点重新收起。「SFTP 初始目录」按钮可回到本次连接的初始位置，「刷新目录」可重新读取当前根目录。

文件树不跟随终端里的 `cd`，也不会向终端注入 `pwd`。终端中选中一行目录路径后，可点击「打开终端选中路径」进行同样的目录验证。包含前后空格的特殊文件名应在路径栏直接输入，以免选中文本时被修剪。

路径栏不展开 `~`、`$HOME` 或 `%USERPROFILE%`。Windows 路径以对方 SFTP 服务实际提供的路径为准；盘符绝对路径可使用 `C:/Users/name` 形式。符号链接不会被自动递归跟随，点击链接时才验证其是否指向可浏览的目录。

## 上传

展开或点击目标目录后，先确认右下方「上传至」显示的路径；尚未选择目录时，目标为文件树根目录。

- 点击「上传」，使用文件选择器选择一个或多个普通文件。
- 或从本机文件管理器拖入文件，放到目标目录行；放到文件树空白处时使用根目录。

文件行不能作为上传目标。悬停不会自动展开目录。提交任务后，改变文件树位置不会改变已有任务的目标。

## 下载

先在右侧「本地下载目录」选择保存位置，再勾选一个或多个文件并点击「下载」。无需为每个任务重复选择目录；修改目录只影响之后提交的任务。

这个下载目录与普通 nooboard 文件接收目录分别管理。下载完成后，可以在底部任务队列点击「在文件管理器中显示」。

目前不支持从远端文件树拖到本机桌面下载，也不递归上传或下载文件夹。需要传送整个文件夹时，可先将其打包为普通文件。

## 任务结果与关闭

同名文件会保留两份，不覆盖已有内容。任务开始后可以取消；失败或取消后可手动重试，重试从头开始，不续传。

「结果待确认」表示保存时没有取得确定答复，文件可能已经到达目标。先检查目标文件与任务提供的临时路径，不要直接重复传输。

关闭会话标签或在终端退出 shell，不会取消健康 SFTP 连接上的上传下载；任务仍显示在底部队列。真正退出 nooboard、系统休眠或文件连接中断会影响任务。任务不支持应用重启后恢复。
