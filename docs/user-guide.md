# 使用指南

[返回 README](../README.md) · [常见问题](troubleshooting.md)

## 连接你的设备

两台电脑都需要运行 nooboard，并能够通过局域网或 VPN 直接访问。

1. 在发起端打开「设备 → 添加设备」。
2. 从「附近设备」选择对方，点击「配对」。
3. 在接收端允许配对，查看本次配对码。
4. 在发起端输入 8 位数字并确认。

配对码 2 分钟后失效，最多尝试三次；失败后可重新发起。配对只需完成一次，正常断线和应用重启不会要求重新输入配对码。

### 附近设备没有出现

在对方「本机信息」中查看配对地址，然后使用「通过地址添加」。地址包含主机名或 IP 及配对端口，例如 `192.168.1.20:24817`。如修改过端口，请以对方界面显示的地址为准。

VPN 可能无法显示附近设备，但仍可以通过可达的 VPN 地址配对。nooboard 不会替你建立 VPN 或配置路由。

### 管理已配对设备

「设备」用于查看连接状态、管理配对和自动发送。手动发送的接收设备在首页或「传输」中选择，设备页不再提供选择和发送入口。名称可以重复，短设备标识可用于区分同名电脑。

设备详情只读显示当前连接的对方 IP 和端口，以及发现的同步地址。当前连接端口可能是对方主动连接时使用的临时端口，与同步监听端口不同。没有当前连接和发现地址时，会将之前保存的地址明确标为「已保存地址」，它可能已过期。连接地址由应用管理，不提供手动修改入口。

| 状态 | 含义与操作 |
| --- | --- |
| 已连接 | 已配对并建立连接；可解除配对。 |
| 已暂停 | 已建立连接，但本机、对方或双方暂停了同步；可恢复本机同步或解除配对。 |
| 离线 | 保留设备记录，但没有连接，也发现不了对方；可解除配对。 |
| 未连接 | 能发现对方，正在自动尝试连接；可解除配对以停止重试。 |
| 未配对 | 能发现对方，并收到已验证的解除配对回执；可重新配对或删除设备信息。 |

收到对方解除配对的通知时，可以选择保留或删除本机设备信息。保留信息不会恢复共享，自动连接尝试会停止。对方离线后显示「离线」；重新发现时会重新核对配对状态，可能短暂显示「未连接」再变为「未配对」。此回执状态不跨应用重启保存。正常重连由应用自动处理，不需要手动断开或重新连接。

解除配对会停止 nooboard 与该设备的剪贴板收发，再次使用需重新配对；本机文字历史仍保留。

## 发送文字

### 手动发送

先在其他应用复制文字，再点击首页木板查看当前剪贴板。选择一台或多台接收设备并发送。每台设备分别显示结果；对方成功接收后，可以直接粘贴。

「已发送」或提交完成不一定表示对方已经应用内容，应以逐设备结果为准。「结果未确认」表示尚未取得确定回执，内容不会自动重发。

### 自动发送

在「设置 → 文字发送模式」选择自动模式，再在「设备」开启目标设备的自动发送。新配对设备的自动发送默认关闭。

自动模式只处理新复制的文字。图片和文件仍需手动发送；收到的文字不会再次自动转发。开启自动发送、恢复同步或设备重连后，不会补发此前的剪贴板内容。

### 暂停与接收开关

- **暂停同步**：停止新的剪贴板收发并取消待发送操作，设备发现、连接维护和配对仍继续。已交付应用或开始接收的内容不保证撤回。连接中的设备显示「已暂停」，并说明由哪一方暂停；双方都暂停时，需要分别恢复。
- **允许接收**：独立控制本机是否接受其他已配对设备的内容。
- **手动模式**：停止自动发送，仍可手动发送及接收。

这些控制针对 nooboard 剪贴板同步。

## 图片和文件

复制图片或普通文件后，可从剪贴板面板手动发送。也可以进入「传输」，点击「选择文件」，选择接收设备后发送。

接收内容默认保存到系统下载目录下的 `Nooboard` 文件夹；在「设置 → 传输 → 默认接收目录」可以修改。新目录只影响之后提交的任务，不会搬走已经接收的文件。

「传输」显示方向、进度、结果和已保存文件。「已保存 · 剪贴板未更新」表示文件已经保存，可使用「重新复制」再尝试放入剪贴板。

普通设备传输支持多个普通文件，不递归传输文件夹；可以先压缩文件夹再发送。同名接收文件不会覆盖已有文件。

默认限制：文字 1 MiB，图片 64 MiB；一批最多 256 个文件，单文件 2 GiB、整批 8 GiB。图片解码和系统剪贴板格式也有大小限制。这些是普通设备传输的限制。

## 文字历史

「文字历史」支持关键词搜索、来源筛选、再次复制和删除记录。历史只包含文字，不保存图片和文件正文。

默认记录最近 30 天、最多 1000 条文字，可在设置中调整。关闭「记录文字历史」会停止新增记录，已有历史不会自动清空。清空历史不会改变当前剪贴板内容，也不会删除接收目录中的文件。

历史保存在本机，未单独加密。不要依赖历史记录来保存密码或其他秘密；被系统格式标记为敏感的内容可能会被跳过，但普通文字中的秘密无法保证被识别。

## 后台运行与退出

支持托盘的平台可以在设置中开启「关闭窗口后继续在后台运行」。启用且托盘可用时，关闭窗口会隐藏应用，剪贴板同步与传输继续运行；从托盘菜单可以重新打开窗口或退出。

托盘不可用时，界面会提示，关闭窗口的行为以所在平台为准。需要结束所有连接和任务时，请完全退出应用。电脑休眠或网络中断仍可能使连接和传输中断。

## 外观与更新

设置中可以切换中文或英文、跟随系统或使用浅色/深色外观，以及减少动态效果。首页的肥啾、木板和信箱用于显示与操作当前状态，传输是否成功以任务结果为准。

应用启动时和每隔六小时会在后台检查并下载新版本。更新准备好后，左下角版本号右侧会出现更新图标，点击后选择“重启更新”。更新会结束当前终端、VPN 和传输任务，再安装并重新启动；应用数据和配置会保留。没有更新时不显示图标，也不需要手动检查。后台检查或下载失败会在下次检查时重试；点击安装后若失败，弹窗会显示错误并允许重试。

尚未包含更新器的旧版本，以及 Linux deb 安装，仍需从 [GitHub Releases](https://github.com/YoRHazero/nooboard/releases) 下载新包，完全退出旧版后安装。Linux 自动更新支持 AppImage。建议配对设备使用相同版本。新版可能升级本机配置或历史数据格式，旧版本不一定能重新读取；升级前有保留需要时应先备份本机应用数据。
